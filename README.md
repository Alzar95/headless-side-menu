# Headless Side Menu Component

React headless компонент бокового меню с поддержкой подменю, адаптивным дизайном и TypeScript, построенный по принципу многоуровневой архитектуры.

## 🚀 Демо

[Посмотреть работающий пример на Vercel](https://headless-side-menu.vercel.app)

## 📋 Особенности

- ✅ **Многоуровневая архитектура** - четкое разделение на Headless (логика), AppMenu (интеграция) и Business-уровень
- ✅ **TypeScript** - полная типизация всех компонентов и пропсов
- ✅ **React Router интеграция** - навигация без просачивания логики в компоненты
- ✅ **Адаптивный дизайн** - автоматическое переключение между desktop и mobile версиями
- ✅ **Tailwind CSS** - современная утилитарная стилизация
- ✅ **Подменю с Drawer** - мобильное меню с оверлеем
- ✅ **Управление состоянием** - только одно открытое подменю одновременно
- ✅ **Гибкая кастомизация** - простой API для бизнес-уровня

## 🏗 Архитектура

Проект построен по трехслойной архитектуре:

### 1. Headless Level (`/headless`)
- **Чистая логика** без стилей и привязки к роутеру
- Управление состоянием (активные элементы, открытые подменю)
- Адаптивность (desktop/mobile режимы)
- Context API для передачи состояния

### 2. Integration Level (`/AppMenu`)
- **Интеграция с React Router**
- Базовая стилизация с Tailwind CSS
- Адаптивный рендеринг (боковое меню для desktop, нижнее для mobile)
- Простой API для бизнес-уровня

### 3. Business Level
- **Декларативное описание** структуры меню
- Минимальная вёрстка без логики
- Легкая поддержка и читаемость
