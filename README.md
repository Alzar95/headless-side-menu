# Headless Side Menu Component

React headless компонент бокового меню с поддержкой подменю, адаптивным дизайном и TypeScript.

## 🚀 Демо

[Посмотреть работающий пример на Vercel](https://headless-side-menu.vercel.app)

## 📋 Особенности

- ✅ **Headless архитектура** - логика отделена от стилей
- ✅ **TypeScript** - полная типизация
- ✅ **React Router интеграция** - без просачивания логики в компонент
- ✅ **Адаптивный дизайн** - desktop + mobile версии
- ✅ **Подменю с Drawer** - мобильное меню с оверлеем

## 🛠 Установка и использование

```bash
npm install
npm run dev
